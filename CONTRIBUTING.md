# Contributing

Thanks for helping keep the Hermes Agent megathreads useful.

## Pull request checklist

Before submitting, please confirm:

- [ ] The provider/model link is official or clearly trustworthy.
- [ ] The free-tier claim is current as of the date you list.
- [ ] You included the date verified.
- [ ] You noted any quota, waitlist, region, or account requirements.
- [ ] If you tested with Hermes, you included the relevant provider compatibility notes.

## Standards

- Prefer primary sources: provider docs, model pages, release notes.
- Mark uncertain items as “unverified” instead of guessing.
- Keep notes practical: what works, what breaks, what limits apply.
- Do not add referral links, affiliate links, or promotional copy.
