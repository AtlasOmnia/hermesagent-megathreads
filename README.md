## How to suggest an update

Use whichever path is easiest:

1. Open an issue with the correction or new provider/model.
2. Click “Edit this file” on GitHub and submit a pull request.
3. Fork the repo, edit locally, and open a pull request.

## What good updates include

For model/API entries, please include:

- provider or model name;
- official website or docs link;
- whether a free tier exists;
- known quota/rate limits;
- whether it is OpenAI-compatible;
- whether you tested it with Hermes Agent;
- date last verified.

No referral spam, affiliate links, or untested claims.
